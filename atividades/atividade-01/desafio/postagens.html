Estrutura de dados

Foca na organização e eficiência da memória. Estuda formas específicas de armazenar e organizar dados (como Arrays, Pilhas, Filas e Árvores) para que possam ser acessados e modificados de forma rápida e otimizada.

Banco de dados

Trata do armazenamento persistente. Envolve a criação, gerenciamento e consulta de dados em sistemas que mantêm a informação salva mesmo após o programa fechar. Utiliza linguagens como SQL para manipular tabelas e registros.

Lógica de programação

É o estudo da construção de algoritmos. Ensina a criar sequências de passos lógicos (instruções) para resolver problemas, utilizando estruturas de controle como loops (for, while) e condicionais (if, else).

Engenharia de software

É a aplicação de processos e metodologias na criação de sistemas. Abrange o ciclo de vida do software: desde o levantamento de requisitos com o cliente e o design da arquitetura até os testes de qualidade e a manutenção.

Redes de Computadores

Estuda a comunicação entre sistemas. Define como os dados são transmitidos entre diferentes dispositivos através de protocolos (como TCP/IP e HTTP), endereçamento (IP) e infraestrutura (cabos, roteadores e Wi-Fi).
